功能 1：Hashtag 抓取（Facebook / Instagram）

调用 Apify 按标签发现帖子，按下方日期范围筛选后导出核心列。发现窗口最多回溯 60 天（与现有 Actor 限制一致）。会产生 Apify 费用。

功能 2：Excel 泰语行筛选

上传 xlsx，按选定文本列用泰语检测保留行。列名可留空自动推断。

功能 3：帖子链接批量抓评论

Excel 需含列 post_url，或使用 url / link / 帖子链接 等列名。每批最多 {{ max_urls }} 条链接（环境变量可配）。结果含评论明细 + 每帖每日新增评论数 Sheet。会产生 Apify 费用；不写主业务评论表。

功能 4：多文件按日加总互动量

每个 xlsx 需包含日期列（date / post_date / 日期）与互动量列（engagement / 互动量）。将多个文件合并后按日期求和。

功能 5：视频链接批量拉播放量

上传含视频链接的 Excel，通过 Apify 批量拉取基础数据并写回原表。支持 TikTok / Instagram / YouTube / Facebook。 链接列默认识别 post_url、url、视频链接 等。每批最多 {{ max_video_urls }} 条链接。会产生 Apify 费用。
