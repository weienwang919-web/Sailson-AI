✉️ 邮件素材提交

一条素材 = 一封信，逐封发给对应收件人 ← 返回首页

1 默认收件邮箱

Excel 里有「收件邮箱」列时以那一列为准，逐行各发各的。 这里填的是兜底值，只在某行没写邮箱时使用。

2 导入 Excel

识别 图片 / name / id / number / 收件邮箱 / 发送状态 六列，图片直接嵌在单元格里。 表头不必在第一行。发送状态非空的行视为已发过，直接跳过； 「收件邮箱 + id」在发信记录里出现过的也会自动跳过，所以同一份表可以反复导入。

拖 .xlsx 到这里，或点击选择
只支持 .xlsx —— .xls 存不了嵌入图片
